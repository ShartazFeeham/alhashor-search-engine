# Alhashor Search Engine

A Hadith search engine that searches a dataset of 33,000+ hadith thousands of times faster than linear search while still matching word by word, delivering accurate results with O(c) complexity.

The app is organized around hadith books and topics: users can browse collections, drill into topics, and run fast full-text searches with relevant word-by-word matching over the large dataset.

## Tech Stack

- React 18 (Create React App)
- React Router DOM
- Bootstrap 5 / React-Bootstrap
- JavaScript (ES6+)

## Getting Started

```sh
git clone https://github.com/ShartazFeeham/alhashor-search-engine.git
cd alhashor-search-engine
npm install
npm start
```

The app runs in development mode at http://localhost:3000.

### Available Scripts

- `npm start` — run the app in development mode
- `npm test` — launch the test runner
- `npm run build` — build the app for production to the `build` folder
